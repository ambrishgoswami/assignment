# Euro Scholars – Study Abroad Website (Redesign of europafusion.io)

Responsive, vector-based redesign of a Germany & Europe study-abroad consultancy site.

## Technologies
- HTML5, CSS3 (custom properties, Grid, Flexbox, media queries), vanilla JavaScript (ES6)
- Inline SVG for all illustrations, icons, avatars and flags (no raster images) – Vector-Based UI
- Google Fonts: Cormorant Garamond + Manrope
- Tooling: VS Code, Claude Code, Chrome DevTools

## Features
- Sticky nav with Destinations mega-menu (9 countries) and Services dropdown
- "Free Profile Evaluation" modal form with validation
- Animated hero, scroll reveal, count-up stats, FAQ accordion, floating WhatsApp button
- Responsive: desktop, tablet (≤900px), mobile (≤560px)

## Run
Open `index.html` in any browser. Files: `index.html`, `style.css`, `script.js`.
